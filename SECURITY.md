# Security policy

## Reporting a vulnerability

If you think you've found a security vulnerability in any Aurium Labs
product or repository, please email **security-alerts@aurium-labs.com**.

Please don't open a public issue or pull request for it.

Include what you can:

- what's affected (product, URL or repository)
- steps to reproduce, or a proof of concept
- the impact you think it has

We'll acknowledge your report within 3 working days and keep you updated
until it's resolved. Please give us a reasonable time to fix the issue
before you disclose it publicly.
