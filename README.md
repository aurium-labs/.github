# .github

Default files for every repository in the `aurium-labs` organisation. A
repository that doesn't have its own copy of a file uses the one here.

| File | Used for |
|---|---|
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | The description every new pull request starts with |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability (shown on each repository's Security tab) |

This repository is **public on purpose**: GitHub only applies these defaults
from a public `.github` repository. It must only ever hold templates and
policies, never code, configuration, credentials or internal details.

Changes go through a pull request with one approval (ruleset on `main`).
